# Gerador de Formulários e Minutas Cartorárias

Aplicação web em React para preenchimento de formulários cartorários e geração de minutas para revisão, cópia e impressão.

## Acesso rápido

- [Abrir o projeto](cartorio-vr-com-minutas/)
- [Ver a documentação completa](cartorio-vr-com-minutas/README.md)
- [Baixar o repositório pelo GitHub](https://github.com/LucasLimaTeixeira/cartorio-vr-formulario-minutas)

## Executar localmente

```bash
cd cartorio-vr-com-minutas
npm install
npm run dev
```

O projeto usa React, TypeScript, Vite e Tailwind CSS. Os dados são processados no navegador e as minutas devem ser revisadas pelo responsável antes de qualquer uso oficial.
